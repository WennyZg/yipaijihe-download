# 一拍即合 · 安卓公开测试

用于安卓手机上的合影拍摄、选脸与合成体验。

## 下载安装

在本仓库的 Releases 页面下载 `yipaijihe-test.apk`，在安卓手机上打开并按系统提示安装。首次使用时允许相机权限。无需电脑、Android Studio 或 USB 调试。

本仓库仅用于发布测试安装包与说明。

## 本次公开测试范围

- 拍照、连拍、合影分析、手动选脸、合成与相册等本地流程供测试体验。
- 在线美颜与风格通过带认证的服务器转发调用，云服务密钥不打包进 APK。首次使用需要开发者提供体验码，并确认照片上传说明。
- 服务器已部署，真实美颜和风格仍在手机验收中；完成验收后发布安装包。
- 这是调试测试版本，尚未完成正式商店发布准备。

## 已有验证

原演示版本已在 Xiaomi 12S Ultra（Android 15）上完成安装、启动及相机取景验证。服务器转发已通过 12 项模拟接口测试，接入转发的客户端已完成构建、签名校验，并已更新安装到测试手机；公网服务已通过认证与健康检查；真实云功能、完整拍照合成及不同机型兼容性仍需验证。

## 建议测试

1. 允许相机权限，确认正常取景。
2. 对准人物拍照，等待连拍和合成完成。
3. 查看相册，测试选脸、保存、重新进入应用后的照片查看。
4. 如遇问题，记录手机型号、安卓版本、操作步骤与错误提示；反馈截图请避开不必要的个人信息。

## 更新与安装

后续正式版可能使用不同的签名。若系统提示签名冲突，请先保留需要的照片，再处理测试版的卸载或迁移。
